Πώς να φτιάξετε ένα GIF σε 4 βήματα

  1. Προσθέστε τις εικόνες σας — αποθέστε τις παραπάνω ή κάντε κλικ για αναζήτηση. Τίποτα δεν μεταφορτώνεται· τα αρχεία παραμένουν στη συσκευή σας.
  2. Τακτοποιήστε τα καρέ — σύρετε τα καρέ στη σειρά που θέλετε ή χρησιμοποιήστε τα κουμπιά πάνω και κάτω. Αφαιρέστε όποιο καρέ δεν χρειάζεστε.
  3. Ρυθμίστε τον χρόνο και το μέγεθος — επιλέξτε καθυστέρηση καρέ (μικρότερη σημαίνει ταχύτερη), πλάτος εξόδου και προαιρετικά διαφορετική καθυστέρηση για ένα μεμονωμένο καρέ. Παρακολουθήστε τη ζωντανή προεπισκόπηση καθώς ρυθμίζετε.
  4. Δημιουργήστε και κατεβάστε — πατήστε Δημιουργία GIF, παρακολουθήστε την πρόοδο και κατεβάστε το κινούμενο GIF που επαναλαμβάνεται.

Γιατί να φτιάξετε το GIF σας εδώ;

Τα περισσότερα online εργαλεία GIF μεταφορτώνουν πρώτα τις φωτογραφίες σας σε έναν διακομιστή. Το Loona GIF Maker δεν το κάνει ποτέ: ο δωρεάν, ανοιχτού κώδικα κωδικοποιητής gif.js εκτελείται εξ ολοκλήρου στο πρόγραμμα περιήγησής σας, ώστε οι εικόνες σας να μην φεύγουν ποτέ από τη συσκευή σας — χωρίς εγγραφή, χωρίς υδατογράφημα και χωρίς όριο από εμάς. Το τελικό GIF επαναλαμβάνεται για πάντα και λειτουργεί παντού όπου μοιράζονται GIF.

Συχνές ερωτήσεις

Είναι δωρεάν το Loona GIF Maker;

Ναι. Το Loona GIF Maker είναι εντελώς δωρεάν — χωρίς εγγραφή, χωρίς υδατογράφημα, χωρίς δοκιμαστική περίοδο και χωρίς όριο στον αριθμό των GIF που δημιουργείτε.

Μεταφορτώνονται οι εικόνες μου σε διακομιστή;

Όχι. Όλα εκτελούνται 100% στο πρόγραμμα περιήγησής σας με JavaScript. Οι εικόνες σας δεν φεύγουν ποτέ από τη συσκευή σας — σε αντίθεση με εργαλεία GIF που βασίζονται σε διακομιστή, όπως το Ezgif, τα οποία απαιτούν πρώτα να μεταφορτώσετε τα αρχεία σας.

Υπάρχει όριο στον αριθμό εικόνων ή στο μέγεθος αρχείου;

Δεν επιβάλλουμε κανένα τεχνητό όριο. Μπορείτε να προσθέσετε όσες εικόνες θέλετε· πολύ μεγάλα σύνολα τεράστιων φωτογραφιών μπορεί να είναι αργά σε ένα τηλέφωνο χαμηλών δυνατοτήτων, οπότε η μείωση του πλάτους εξόδου βοηθά.

Ποιες μορφές εικόνας μπορώ να χρησιμοποιήσω;

Οποιαδήποτε μορφή μπορεί να εμφανίσει το πρόγραμμα περιήγησής σας — JPG, PNG, WebP, GIF, BMP και άλλες. Τα καρέ συνδυάζονται σε ένα κινούμενο GIF.

Θα επαναλαμβάνεται το GIF μου για πάντα;

Ναι. Τα GIF που δημιουργούνται εδώ ρυθμίζονται να επαναλαμβάνονται για πάντα (repeat 0), ώστε να παίζουν συνεχώς όπου κι αν δημοσιευτούν.

Μπορώ να αλλάξω την ταχύτητα μεμονωμένων καρέ;

Ναι. Ορίστε μια συνολική καθυστέρηση καρέ για ολόκληρο το GIF και στη συνέχεια παρακάμψτε την καθυστέρηση σε οποιοδήποτε μεμονωμένο καρέ στη λίστα καρέ.
