Γεννήτρια Διαβαθμίσεων CSS

Δημιουργήστε ένα γραμμική διαβάθμιση από δύο ή τρία χρώματα, γυρίστε το σε οποιαδήποτε γωνία με ζωντανή προεπισκόπηση, και αντιγράψτε το έτοιμο προς επικόλληση CSS.

Η γωνία ακολουθεί το πρότυπο CSS: 0deg δείχνει πάνω, 90deg δείχνει δεξιά, 180deg δείχνει κάτω. Οι στάσεις χρώματος απέχουν ομοιόμορφα — δύο χρώματα στο 0% και 100%, τρία στο 0%, 50% και 100%.

Πώς να δημιουργήσετε μια διαβάθμιση CSS σε 3 βήματα

  1. Επιλέξτε δύο ή τρία χρώματα — σημειώστε το τρίτο πλαίσιο χρώματος για μια διαβάθμιση τριών στάσεων.
  2. Ορίστε τη γωνία — σύρετε το ρυθμιστικό και παρακολουθήστε την προεπισκόπηση να γυρίζει σε πραγματικό χρόνο.
  3. Κάντε κλικ στο CSS για να το αντιγράψετε — επικολλήστε το απευθείας στο φύλλο στυλ ή το χαρακτηριστικό στυλ σας.

Διαβαθμίσεις που δείχνουν σχεδιασμένες, όχι προεπιλεγμένες

Μια γραμμική διαβάθμιση αναμειγνύει ένα χρώμα σε ένα άλλο κατά μήκος μιας ευθείας γραμμής. Τα κλασικά λάθη είναι η επιλογή χρωμάτων από αντίθετα άκρα του ουράνιου τόξου (η ανάμειξη γίνεται λασπώδες γκρι στη μέση) και η χρήση καθαρών στάσεων ουράνιου τόξου. Οι αξιόπιστες συνταγές: αναμείξτε δύο αποχρώσεις του ίδιο οικογένεια απόχρωσης για ένα διακριτικό, επαγγελματικό φόντο· προσθέστε ένα τρίτο χρώμα όταν η ανάμειξη δύο χρωμάτων έχει ένα θαμπό μέσο· και ταιριάξτε τη γωνία με το φως στο σχέδιό σας — 135° (πάνω-αριστερά προς κάτω-δεξιά) ταιριάζει στις περισσότερες οθόνες επειδή μιμείται το φυσικό φως. Εάν χρειάζεστε ένα αρχικό ζεύγος, δημιουργήστε πρώτα μια παλέτα με τη Γεννήτρια Παλετών Loona και επικολλήστε τους κωδικούς HEX της εδώ.

Πώς λειτουργεί

Η γεννήτρια γράφει το τυπικό CSS linear-gradient() συνάρτηση για εσάς. Οι στάσεις χρώματος απέχουν ομοιόμορφα: με δύο χρώματα κάθονται στο 0% και 100%· με τρία, στο 0%, 50% και 100%. Η γωνία χρησιμοποιεί τη σύμβαση CSS — 0deg δείχνει προς τα πάνω, 90deg προς τα δεξιά, 180deg προς τα κάτω, 270deg προς τα αριστερά — και το ίδιο το πρόγραμμα περιήγησης αποδίδει την ανάμειξη, οπότε η προεπισκόπηση που βλέπετε είναι ακριβώς αυτό που παράγει ο αντιγραμμένος κώδικας. Κανένας κώδικας δεν φεύγει από τη συσκευή σας· το CSS συναρμολογείται στο πρόγραμμα περιήγησής σας.

Λυμένο παράδειγμα

Επιλέξτε κόκκινο #ff0000 και μπλε #0000ff στις 90 μοίρες και η έξοδος είναι background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — η ανάμειξη τρέχει αριστερά (0deg θα έτρεχε προς τα πάνω) προς τα δεξιά, ξεκινώντας καθαρό κόκκινο και τελειώνοντας καθαρό μπλε. Προσθέστε ένα μεσαίο χρώμα, ας πούμε χρυσό #d4a017, και τοποθετείται στο 50%: linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%).

Συχνές ερωτήσεις

Είναι αυτή η γεννήτρια διαβαθμίσεων δωρεάν;

Ναι — δωρεάν χωρίς εγγραφή, και το CSS που παράγει είναι δικό σας να το χρησιμοποιείτε οπουδήποτε, συμπεριλαμβανομένων εμπορικών έργων.

Ποια είναι η διαφορά μεταξύ 0deg και 180deg;

Τρέχουν την ίδια ανάμειξη σε αντίθετες κατευθύνσεις: 0deg ξεκινά το πρώτο χρώμα στο κάτω μέρος και αναμειγνύει προς τα πάνω· 180deg το ξεκινά στο επάνω μέρος και αναμειγνύει προς τα κάτω. Εναλλάξτε τη γωνία κατά 180 για να αντιστρέψετε οποιαδήποτε διαβάθμιση.

Μπορώ να φτιάξω μια ακτινωτή διαβάθμιση;

Αυτό το εργαλείο χτίζει γραμμικές διαβαθμίσεις, που καλύπτουν τις περισσότερες ανάγκες σχεδίασης ιστού. Για ακτινική έκδοση, δημιουργήστε τα χρώματα εδώ, στη συνέχεια αλλάξτε το όνομα συνάρτησης στο CSS σας σε radial-gradient με τις ίδιες στάσεις χρώματος.

Γιατί η ανάμειξη δύο χρωμάτων μου δείχνει γκρι στη μέση;

Χρώματα απέναντι το ένα από το άλλο στον τροχό ακυρώνονται στη μέση της ανάμειξης. Προσθέστε ένα τρίτο χρώμα ανάμεσά τους (επιλέξτε Χρώμα 3) που γεφυρώνει τις δύο αποχρώσεις, και η λασπώδης ζώνη εξαφανίζεται.

Θα λειτουργεί η διαβάθμιση σε όλα τα προγράμματα περιήγησης;

Ναι — το linear-gradient υποστηρίζεται από κάθε σύγχρονο πρόγραμμα περιήγησης εδώ και πάνω από μια δεκαετία, χωρίς προθέματα. Η προεπισκόπηση χρησιμοποιεί το ίδιο CSS, οπότε αυτό που βλέπετε είναι αυτό που παίρνετε.
