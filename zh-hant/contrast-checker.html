對比度檢查器

檢查您的 文字和背景顏色 對每個人都可讀：即時 WCAG 對比度，帶 AA 和 AAA 判定和實時預覽。

如何透過 3 個步驟檢查顏色對比度

  1. 輸入兩種顏色 — 文字顏色和它所在的背景顏色，透過選擇器或 HEX 程式碼。
  2. 讀取比例和徽章 — AA 是大多數網站應達到的標準；AAA 是更嚴格的級別。
  3. 調整直到它透過 — 一次一步地加深文字或增亮背景；預覽實時更新，因此您可以看到對真實文字的效果。

為什麼對比度是規則，而不是品味

網路內容無障礙指南（WCAG）設定了最低對比度，以便文字對低視力、色覺缺陷、老化眼睛的人 — 以及每個在明亮陽光下閱讀手機的人 — 保持可讀。AA 級別被寫入許多無障礙法律和採購規則：普通文字需要至少以下比例： 4.5 : 1，以及大文字（18 點或 14 點粗體及以上）至少為 3 : 1。AAA 級別將這些標準提高到 7 : 1 和 4.5 : 1。1 : 1 的比例意味著顏色相同（不可見的文字）；21 : 1 是白底黑字，是可能的最大值。

它如何工作

每種顏色都轉換為其 相對亮度：RGB 通道使用 WCAG 公式線性化（撤銷伽馬）— 當通道最多為 0.03928 時為通道 ÷ 12.92，否則為 ((通道 + 0.055) ÷ 1.055)2.4 — 然後組合為 L = 0.2126·R + 0.7152·G + 0.0722·B。對比度是（較亮的 L + 0.05）÷（較暗的 L + 0.05）。綠色在權重中佔主導，因為人眼對它最敏感，這就是為什麼在相同數字強度下，純綠色文字看起來比純藍色更亮。數學運算完全在您的瀏覽器中執行。

例項講解

白色背景上的黑色文字得分 21.00 : 1 — 最大值。灰色是有趣的邊界情況： #767676 在白色上的得分為 4.54 : 1 並且剛剛透過普通文字的 AA，而淺一個步長時， #777777，得分 4.48 : 1 並且剛剛失敗。一個 HEX 步長可以是可訪問和不可訪問之間的區別 — 這正是檢查勝過猜測的原因。

常見問題

這個對比度檢查器免費嗎？

是的 — 免費、無限制、無需註冊。一切都在您的瀏覽器中計算。

我的網站文字應該以什麼比例為目標？

正文文字至少 4.5 : 1（WCAG AA）。儘可能以 7 : 1（AAA）為目標，尤其是長篇閱讀。標題和其他大文字至少需要 3 : 1。

對比度也適用於徽標和圖示嗎？

WCAG 豁免徽標，但基本圖示和介面控制元件對相鄰顏色有自己的 3 : 1 指南。正文文字、連結和表格標籤是此檢查器的用途。

我的品牌顏色在白色上不合格。我該怎麼辦？

將品牌顏色用於大標題和圖形，並將相同色調的較暗陰影用於正文文字。Loona 顏色選擇器的色調和陰影條為您提供那些較暗的步長；在此處重新檢查陰影。

用本工具檢查足以滿足法律合規嗎？

它精確地驗證對比度要求，但 WCAG 涵蓋的內容要多得多（鍵盤訪問、替代文字、焦點順序等）。將此處的透過視為一項要求得到妥善滿足，而不是一次完整的稽核。
