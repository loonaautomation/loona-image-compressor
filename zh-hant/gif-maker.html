4 步製作 GIF

  1. 加入您的圖片 — 將它們拖放到上方，或點擊瀏覽。不會上傳任何內容；檔案只保留在您的裝置上。
  2. 排列畫面順序 — 拖動畫面進行排序，或使用上移和下移按鈕。刪除任何不需要的畫面。
  3. 設定速度和尺寸 — 選擇畫面延遲（數值越小播放越快）、輸出寬度，還可以為單個畫面設定不同的延遲。調整時可以觀看即時預覽。
  4. 建立並下載 — 點擊「建立 GIF」，等待處理完成，然後下載您的循環動畫 GIF。

為什麼在這裡製作 GIF？

大多數線上 GIF 製作工具會先把您的照片上傳到伺服器。Loona GIF Maker 從不這樣做：免費的開源 gif.js 編碼器完全在您的瀏覽器中執行，因此您的圖片絕不會離開您的裝置，無需註冊、無浮水印，我們也不設任何限制。完成的 GIF 會無限循環，在任何可以分享 GIF 的地方都能播放。

常見問題

Loona GIF Maker 是免費的嗎？

是的。Loona GIF Maker 完全免費 — 無需註冊、無浮水印、無試用限制，您可以製作的 GIF 數量也沒有上限。

我的圖片會被上傳到伺服器嗎？

不會。一切都透過 JavaScript 100% 在您的瀏覽器中執行。您的圖片絕不會離開您的裝置 — 與 Ezgif 等以伺服器為基礎的 GIF 製作工具不同，那些工具要求您先上傳檔案。

圖片數量或檔案大小有限制嗎？

我們不設任何人為限制。您可以加入任意數量的圖片；如果在低階手機上處理大量超大照片，速度可能會較慢，減小輸出寬度會有幫助。

我可以使用哪些圖片格式？

任何您的瀏覽器可以顯示的格式 — JPG、PNG、WebP、GIF、BMP 等。這些畫面會被組合成一個動畫 GIF。

我的 GIF 會無限循環播放嗎？

是的。在這裡建立的 GIF 都設定為無限循環（repeat 0），因此無論發佈到哪裡都會連續播放。

我可以更改單個畫面的播放速度嗎？

可以。先為整個 GIF 設定一個全域畫面延遲，然後在畫面清單中為任意單個畫面單獨設定不同的延遲。
