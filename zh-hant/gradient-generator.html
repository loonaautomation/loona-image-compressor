CSS 漸變生成器

構建一個 線性漸變 從兩種或三種顏色生成，將其轉動到任何角度（帶實時預覽），並複製可直接貼上的 CSS。

角度遵循 CSS 標準：0deg 指向上，90deg 指向右，180deg 指向下。色標均勻分佈 — 兩種顏色在 0% 和 100%，三種在 0%、50% 和 100%。

如何透過 3 個步驟構建 CSS 漸變

  1. 選擇兩種或三種顏色 — 勾選第三個顏色框以獲得三段漸變。
  2. 設定角度 — 拖動滑塊，觀看預覽實時旋轉。
  3. 點選 CSS 以複製它 — 將其直接貼上到您的樣式表或樣式屬性中。

看起來是設計出來的漸變，而不是預設的

線性漸變沿直線將一種顏色混合到另一種顏色中。經典的錯誤是從彩虹的兩端選擇顏色（混合在中間變成渾濁的灰色）和使用純彩虹色標。可靠的方法是：混合以下顏色的兩種色調： 相同 色調系列，用於微妙、專業的背景；當雙色混合的中間暗淡時，新增第三種顏色；並使角度與您設計中的光線相配 — 135°（左上到右下）適合大多數螢幕，因為它模仿自然光。如果您需要一個起始配對，先用 Loona 調色盤生成器生成一個調色盤，並將其 HEX 程式碼貼上到此處。

它如何工作

生成器寫入標準 CSS linear-gradient() 為您（生成漸變的）函式。色標均勻分佈：兩種顏色時它們位於 0% 和 100%；三種時位於 0%、50% 和 100%。角度使用 CSS 約定 — 0deg 指向上，90deg 指向右，180deg 指向下，270deg 指向左 — 瀏覽器本身渲染混合，因此您看到的預覽正是複製的程式碼產生的結果。沒有程式碼離開您的裝置；CSS 在您的瀏覽器中組裝。

例項講解

選擇紅色 #ff0000 和藍色 #0000ff 在 90 度時，輸出是 background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — 混合從左（0deg 會向上執行）到右執行，從純紅開始，到純藍結束。新增中間顏色，比如金色 #d4a017，並將其放置在 50%： linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%)。

常見問題

這個漸變生成器免費嗎？

是的 — 免費、無需註冊，它產生的 CSS 是您的，可以在任何地方使用，包括商業專案。

0deg 和 180deg 之間有什麼區別？

它們以相反方向執行相同的混合：0deg 從底部開始第一種顏色並向上混合；180deg 從頂部開始並向下混合。將角度交換 180 以反轉任何漸變。

我可以製作徑向漸變嗎？

本工具構建線性漸變，它覆蓋了大多數網頁設計需求。對於徑向版本，在此處生成顏色，然後將 CSS 中的函式名更改為 radial-gradient，使用相同的色標。

為什麼我的雙色混合在中間看起來是灰色的？

色輪上彼此相對的顏色在混合中途會相互抵消。在它們之間新增第三種顏色（勾選顏色 3）來連線兩種色調，渾濁的帶就會消失。

漸變會在所有瀏覽器中都有效嗎？

是的 — linear-gradient 已經被每個現代瀏覽器支援了十多年，無需字首。預覽使用相同的 CSS，因此您所見即所得。
