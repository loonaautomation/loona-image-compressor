一種顏色，四種語言

設計師、開發人員和照片編輯人員對同一種顏色的描述各不相同。HEX（#d4a017）是網頁設計和 CSS 中使用的簡寫。RGB 列出了要混合多少紅光、綠光和藍光 — 這是螢幕的語言。HSL 和 HSV 以人們思考顏色的方式來描述顏色：色輪上的色調、它的鮮豔程度，以及它的明亮程度。手動在它們之間轉換容易出錯；本工具在您嘗試時會保持四者同步，色調和陰影條以均勻的 20% 步長顯示同一色調向白色和向黑色混合的結果 — 這是構建懸停狀態、邊框顏色或仍屬於同一家族的柔和背景的最快方法。

它如何工作

HEX 只是以 16 進位制書寫的 RGB：每對數字是一個從 0（00）到 255（ff）的通道。HSL 從最大和最小的 RGB 通道計算得出：亮度是它們的中點，飽和度是它們之間的差距按該中點縮放，色調是色輪上指向主導通道的角度。HSV（也稱為 HSB）使用相同的色調，但相對於最亮的通道測量飽和度，並將該通道直接報告為值。所有轉換都使用標準 CSS 顏色數學在您的瀏覽器中執行 — 沒有圖片或顏色會離開您的裝置。

例項講解

取橙色 #FF6600。在 RGB 中，那是 rgb(255, 102, 0) — 全紅、一些綠、無藍。HSL 轉換得到 hsl(24°, 100%, 50%)：24° 的色調位於紅色（0°）和黃色（60°）之間，正是橙色所在的位置，飽和度為滿，亮度為一半。HSV 報告 hsv(24°, 100%, 100%) — 相同的色調、完全飽和、完全亮度，因為最強的通道（紅色）處於最大值。

常見問題

這個顏色選擇器免費嗎？

是的 — 完全免費、無需註冊、無限制。點選任何值以複製它。

HSL 和 HSV 之間有什麼區別？

它們共享相同的色調。HSL 亮度是最亮和最暗通道之間的中點，因此 50% 亮度是純色。HSV 值就是最亮的通道，因此 100% 值是全亮度下的純色。設計工具各不相同：Figma 顯示 HEX/RGB/HSL，Photoshop 的選擇器基於 HSV。

我可以輸入我已有的 HEX 程式碼嗎？

是的 — 在 HEX 框中輸入或貼上任何 3 位或 6 位 HEX 值（帶或不帶 #），然後按 Enter。所有其他格式和兩組滑塊同時更新。

什麼是色調和陰影？

色調是與白色混合的顏色；陰影是與黑色混合的顏色。選擇器下方的條以 20% 的步長移動，這是匹配懸停、邊框和背景顏色的實用方法。

這適用於印刷顏色（CMYK）嗎？

本工具涵蓋螢幕顏色模型（HEX、RGB、HSL、HSV）。CMYK 轉換取決於印表機配置檔案，因此對於列印工作，請將這些值用作起點並在紙上校樣。
