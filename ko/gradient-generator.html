CSS 그라데이션 생성기

다음을 만드세요 선형 그라데이션 두세 가지 색상에서, 실시간 미리보기와 함께 모든 각도로 돌리고, 붙여넣을 준비가 된 CSS를 복사하세요.

각도는 CSS 표준을 따라요: 0deg는 위를, 90deg는 오른쪽을, 180deg는 아래를 가리켜요. 색상 정지점은 고르게 간격을 둬요 — 두 가지 색상은 0%와 100%에, 세 가지는 0%, 50%, 100%에.

3단계로 CSS 그라데이션을 만드는 방법

  1. 두세 가지 색상 선택 — 세 가지 정지점 그라데이션을 위해 세 번째 색상 상자를 체크하세요.
  2. 각도 설정 — 슬라이더를 드래그하고 미리보기가 실시간으로 바뀌는 것을 보세요.
  3. CSS를 클릭해 복사 — 스타일시트나 스타일 속성에 바로 붙여넣으세요.

기본값이 아닌 디자인된 것처럼 보이는 그라데이션

선형 그라데이션은 직선을 따라 한 색상을 다른 색상으로 섞어요. 고전적인 실수는 무지개의 반대쪽 끝에서 색상을 고르는 것(섞으면 가운데가 탁한 회색이 돼요)과 순수한 무지개 정지점을 사용하는 것이에요. 신뢰할 수 있는 조리법: 다음의 두 가지 음영을 섞으세요 same 미묘하고 전문적인 배경을 위한 색조 계열; 두 색상 혼합의 가운데가 dull하면 세 번째 색상을 추가하세요. 그리고 각도를 디자인의 빛에 맞추세요 — 135° (왼쪽 위에서 오른쪽 아래로)는 자연광을 모방하므로 대부분의 화면에 적합해요. 시작 쌍이 필요하면, 먼저 Loona 팔레트 생성기로 팔레트를 생성하고 그 HEX 코드를 여기에 붙여넣으세요.

작동 방식

생성기는 표준 CSS를 써요 linear-gradient() 당신을 위해 함수예요. 색상 정지점은 고르게 간격을 둬요: 두 가지 색상에서는 0%와 100%에 앉아요. 세 가지에서는 0%, 50%, 100%에. 각도는 CSS 관례를 사용해요 — 0deg는 위를, 90deg는 오른쪽을, 180deg는 아래를, 270deg는 왼쪽을 가리켜요 — 그리고 브라우저 자체가 혼합을 렌더링하므로, 보이는 미리보기가 복사한 코드가 만드는 것과 정확히 같아요. 어떤 코드도 기기를 벗어나지 않아요. CSS는 브라우저에서 조립돼요.

적용 예시

빨간색 선택 #ff0000 그리고 파란색 #0000ff 90도에서, 그리고 출력은 다음과 같아요 background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — 혼합은 왼쪽(0deg는 위로 실행돼요)에서 오른쪽으로 실행되며, 순수한 빨간색에서 시작해 순수한 파란색으로 끝나요. 가운데 색상을 추가하세요, 예를 들어 황금 #d4a017, 그리고 50%에 배치돼요: linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%).

자주 묻는 질문

이 그라데이션 생성기는 무료인가요?

네 — 회원가입 없이 무료이고, 만드는 CSS는 상업 프로젝트를 포함해 어디서나 사용할 수 있어요.

0deg와 180deg의 차이는 무엇인가요?

같은 혼합을 반대 방향으로 실행해요: 0deg는 첫 색상을 아래쪽에서 시작해 위로 섞어요. 180deg는 위쪽에서 시작해 아래로 섞어요. 각도를 180만큼 교환해 모든 그라데이션을 뒤집으세요.

방사형 그라데이션을 만들 수 있나요?

이 도구는 선형 그라데이션을 만들며, 이는 대부분의 웹 디자인 필요를 다뤄요. 방사형 버전에서는, 여기서 색상을 생성한 뒤, CSS의 함수 이름을 같은 색상 정지점의 radial-gradient로 바꾸세요.

왜 두 색상 혼합이 가운데에서 회색으로 보이나요?

색상환의 반대쪽에 있는 색상은 섞는 도중에 서로 상쇄돼요. 두 색조를 잇는 세 번째 색상을 사이에 추가하면(색상 3 체크), 탁한 띠가 사라져요.

그라데이션이 모든 브라우저에서 작동하나요?

네 — linear-gradient는 접두사 없이 십 년 넘게 모든 최신 브라우저가 지원해왔어요. 미리보기는 같은 CSS를 사용하므로, 보는 것이 얻는 것이에요.
