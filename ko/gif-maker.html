4단계로 GIF 만드는 방법

  1. 이미지 추가 — 위에 드롭하거나 클릭해서 찾아보세요. 아무것도 업로드되지 않으며 파일은 기기에 남아요.
  2. 프레임 정렬 — 프레임을 드래그해 순서를 정하거나 위아래 버튼을 사용하세요. 필요 없는 프레임은 제거하세요.
  3. 시간과 크기 설정 — 프레임 지연(작을수록 빠름), 출력 너비를 선택하고, 원하면 단일 프레임의 지연을 따로 지정하세요. 조정하면서 실시간 미리보기를 확인하세요.
  4. 만들기와 다운로드 — GIF 만들기를 누르고 진행 상황을 본 뒤, 반복 재생되는 애니메이션 GIF를 다운로드하세요.

왜 여기서 GIF를 만들어야 하나요?

대부분의 온라인 GIF 메이커는 먼저 사진을 서버에 업로드해요. Loona GIF Maker는 절대 그러지 않아요: 무료 오픈소스 gif.js 인코더가 브라우저에서 완전히 실행되므로 이미지가 기기를 떠나지 않고, 회원가입도, 워터마크도, 저희가 부과하는 제한도 없어요. 완성된 GIF는 영원히 반복 재생되며 GIF가 공유되는 모든 곳에서 작동해요.

자주 묻는 질문

Loona GIF Maker는 무료인가요?

네. Loona GIF Maker는 완전히 무료예요 — 회원가입 없음, 워터마크 없음, 체험판 없음, 만들 수 있는 GIF 수의 제한도 없어요.

내 이미지가 서버에 업로드되나요?

아니요. 모든 것이 JavaScript로 브라우저에서 100% 실행돼요. 이미지는 기기를 절대 떠나지 않아요 — 먼저 파일을 업로드해야 하는 Ezgif 같은 서버 기반 GIF 메이커와는 달라요.

이미지 수나 파일 크기에 제한이 있나요?

인위적인 제한은 두지 않아요. 원하는 만큼 이미지를 추가할 수 있어요; 아주 큰 사진이 많은 세트는 저사양 휴대폰에서 느릴 수 있으니 출력 너비를 줄이면 도움이 돼요.

어떤 이미지 형식을 사용할 수 있나요?

브라우저가 표시할 수 있는 모든 형식 — JPG, PNG, WebP, GIF, BMP 등. 프레임들이 하나의 애니메이션 GIF로 결합돼요.

내 GIF가 영원히 반복 재생되나요?

네. 여기서 만든 GIF는 영원히 반복 재생(repeat 0)되도록 설정되어 게시되는 곳마다 계속 재생돼요.

개별 프레임의 속도를 바꿀 수 있나요?

네. GIF 전체에 대한 전역 프레임 지연을 설정한 뒤, 프레임 목록에서 단일 프레임의 지연을 재정의하세요.
