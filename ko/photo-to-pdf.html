3단계로 사진을 PDF로 바꾸는 방법

  1. 사진 추가 — 위에 놓거나 클릭해 찾아보고 한 번에 여러 개를 선택하세요. 아무것도 업로드되지 않아요. 사진은 기기에 남아요.
  2. 정렬하고 설정 선택 — 목록 순서가 페이지 순서예요. 원하지 않는 사진을 제거한 뒤, 페이지 크기(A4, Letter, 이미지에 맞춤), 여백, 방향을 고르세요.
  3. PDF 만들기 — 페이지당 사진 한 장, 왜곡 없이 페이지에 맞게 조정되어, 하나의 다음으로 저장돼요 photos.pdf file.

사진을 PDF로 바꾸는 것에 대해

신청, 대학, 정부 포털은 보통 문서를 "하나의 PDF로" 요청해요: 자격증, 신분증, 양식의 휴대폰 사진 세트는 이메일 첨부나 포털 업로드 전에 하나의 단정한 파일이 되어야 해요. PDF는 모든 페이지를 고정 크기로 유지하므로, 받는 사람은 메일 앱이 선택하는 순서의 느슨한 이미지 파일 더미 대신, A4나 Letter 용지에 합리적인 여백으로 만든 레이아웃을 정확히 봐요.

이 변환기는 오픈 소스 pdf-lib 라이브러리로 전적으로 브라우저에서 PDF를 만들어요 — 우리의 Loona PDF Tools가 사용하는 같은 라이브러리예요. 각 사진은 자체 페이지에 배치되고, 페이지 여백 안에 맞게 비례 조정되므로, 아무것도 늘어나거나 잘리지 않아요. JPEG와 PNG 사진은 원래 품질로 직접 임베드돼요. WebP 같은 기타 형식은 먼저 브라우저에서 캔버스로 고품질 JPEG로 변환돼요.

작동 방식

모든 사진에 대해 도구는 페이지에서 여백을 뺀 안에 들어가는, 사진의 종횡비를 가진 가장 큰 직사각형을 계산하고, 페이지 가운데에 배치하며, 거기에 이미지를 임베드해요. "자동" 방향에서는 넓은 가로 사진은 자동으로 가로 페이지를 얻고 긴 세로 사진은 세로 페이지를 얻어요. "이미지에 맞춤"에서는 각 페이지가 정확히 사진의 모양으로 대신 만들어져요.

적용 예시

3000 × 2000 px 가로 사진을 A4 세로 페이지(595 × 842 pt)에 일반 36 pt 여백으로 두면 523 × 770 pt의 사용 가능 공간이 남아요. 사진은 min(523/3000, 770/2000) ≈ 0.174만큼 조정되어, 배치 크기가 약 다음과 같아요 523 × 349 pt, 페이지 가운데에 — 전체 너비로, 위와 아래에 균일한 흰 여백과 함께, 왜곡 없이.

자주 묻는 질문

이 사진에서 PDF로 변환기는 무료인가요?

네 — 완전히 무료, 회원가입 없음, 워터마크 없음, 사진이나 PDF 수에 제한 없음.

하나의 PDF에 사진을 몇 장 넣을 수 있나요?

기기의 메모리가 편안하게 담을 수 있는 만큼 — 각 사진은 표시된 순서대로 한 페이지가 돼요. 매우 큰 세트(전체 크기 휴대폰 사진 수십 장)에서는 결과 PDF도 커져요. 사진이 원본 품질로 임베드되기 때문이에요.

사진이 PDF에서 품질을 잃나요?

JPEG와 PNG 사진은 원래 품질로 바이트 단위로 임베드돼요. WebP와 기타 형식은 먼저 고품질 JPEG로 변환되며, 이는 사진에서는 시각적으로 동일해요.

페이지 순서를 바꿀 수 있나요?

페이지 순서는 목록의 순서를 따르며, 이는 사진을 선택한 순서예요. 사진을 제거하고 다시 추가하면 끝으로 이동해요, 또는 처음부터 원하는 순서로 파일을 선택하세요.

내 사진이 어디엔가 업로드되나요?

아니요. PDF는 pdf-lib로 브라우저에서 100% 만들어져요. 사진은 기기를 절대 벗어나지 않아요.

PDF 만들기 버튼이 아무것도 하지 않으면 어떻게 되나요?

도구는 공개 CDN에서 로드되는 pdf-lib 라이브러리가 필요해요 — 인터넷 연결을 확인하고 페이지를 다시 로드하세요. 라이브러리가 로드될 수 없으면, 도구는 조용히 실패하는 대신 명확한 오류 메시지를 보여줘요.
