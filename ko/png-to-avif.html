PNG를 AVIF로 변환하는 변환기

PNG 이미지를 AVIF로 변환하세요 — 무료이고 즉각적이며 비공개예요: 변환은 전적으로 브라우저에서 실행돼요.

🔁
PNG 파일을 여기에 놓거나 클릭해서 찾아보세요
브라우저 자체 이미지 엔진으로 사용자의 기기에서 변환돼요 — 절대 업로드되지 않아요.

⬇️ AVIF 다운로드

시작하려면 PNG 파일을 추가하세요.

PNG를 AVIF로 변환하는 이유

큰 PNG 스크린샷과 그래픽은 AVIF로 극적으로 줄어요.

파일에서 무엇이 바뀌나요

AVIF는 낮은 비트레이트에서 평면 그래픽과 텍스트를 PNG만큼 깔끔하게 처리하지 못해요 — PNG를 삭제하기 전에 결과에서 가장자리와 작은 텍스트를 확인하세요.

실제 예시

위에 놓은 PNG 파일은 정확한 픽셀 크기를 유지해요(같은 너비와 높이의 AVIF). 바뀌는 것은 인코딩뿐이에요. 결과 줄은 변환 전/후 파일 크기를 보여주므로 도움이 됐는지 바로 판단할 수 있어요 — AVIF가 더 커지면(작은 PNG 그래픽을 BMP로 바꿀 때 흔해요) 정직한 숫자 덕분에 원본을 유지할 수 있어요.

자주 묻는 질문

PNG를 AVIF로 어떻게 변환하나요?

위에 PNG 파일을 추가하고 변환을 누르세요 — 브라우저 자체 이미지 엔진이 AVIF로 다시 인코딩하고, 결과를 다운로드할 수 있어요. 아무것도 업로드되지 않아요.

PNG를 AVIF로 변환하면 품질이 떨어지나요?

AVIF는 낮은 비트레이트에서 평면 그래픽과 텍스트를 PNG만큼 깔끔하게 처리하지 못해요 — PNG를 삭제하기 전에 결과에서 가장자리와 작은 텍스트를 확인하세요.

파일 크기 제한이 있나요?

사용자 기기의 메모리뿐이에요. 아주 큰 이미지(100+ 메가픽셀)는 휴대폰에 부담을 줄 수 있어요 — 데스크톱은 쉽게 처리해요.

도구가 거부하는 이유는 무엇인가요?

최신 브라우저에서 JPG/PNG/WebP/GIF/BMP/SVG 디코딩은 보편적이지만, AVIF 인코딩(그리고 Firefox의 WebP)은 모든 곳에서 사용할 수 없어요. 도구는 이를 감지해 잘못된 형식의 파일을 만드는 대신 솔직하게 알려줘요.
