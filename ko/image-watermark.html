이미지 워터마크

모든 사진에 이름, 브랜드, 저작권 텍스트를 추가하세요 — 다음을 설정하세요 텍스트, 크기, 색상, 불투명도, 위치, 또는 전체 이미지에 타일 패턴으로 반복해요. 실시간 미리보기, 즉시 다운로드, 그리고 모든 것은 브라우저에서 일어나요: 사진은 절대 업로드되지 않아요.

💧
image을 여기에 놓거나 클릭해서 찾아보세요
JPG, PNG 또는 WebP. 워터마크는 아래 미리보기에 실시간으로 그려져요.

아직 로드된 이미지가 없어요.

이미지를 로드하고, 워터마크 텍스트를 입력하면, 미리보기가 실시간으로 업데이트돼요.

3단계로 워터마크를 추가하는 방법

  1. 이미지 로드 — 위에 놓거나 클릭해 찾아보세요. 아무것도 업로드되지 않아요. 이미지는 기기에 남아요.
  2. 텍스트를 입력하고 스타일 지정 — 텍스트, 크기, 색상, 불투명도를 설정한 뒤, 아홉 위치 중 하나를 고르세요 — 또는 전체 사진에 텍스트를 반복하려면 타일 패턴을 켜세요.
  3. Download — 설정을 바꾸면 미리보기가 실시간으로 업데이트돼요. 올바르게 보이면, JPG, PNG, WebP로 다운로드하세요.

사진에 워터마크를 넣는 것에 대해

워터마크는 사진에 직접 그려진 이름, 로고 텍스트, 저작권 줄이에요. 사진가, 온라인 판매자, 교사가 사용하며, 이미지가 공유, 저장, 재게시될 때 소유자가 여전히 보이도록 해요. 약 50–70% 불투명도의 모서리 워터마크는 포트폴리오와 제품 사진에서 인기 있는 선택이에요: 읽을 수 있을 만큼 선명하고, 그림을 망치지 않을 만큼 가벼워요. 전체 이미지에 반복되는 타일 패턴은 미리보기와 교정본에 더 강한 선택이에요. 잘라낼 깨끗한 모서리가 남지 않기 때문이에요.

워터마크가 하는 일에 현실적이 되세요: 가벼운 복사를 막고 소유권을 증명하지만, 결심한 사람은 여전히 잘라내거나 편집할 수 있어요. 민감한 문서에서는 워터마크를 원본 파일 보관과 함께 사용하세요 — 원본, 표시 없는 사본이 사진이 당신의 것임을 보여주는 가장 강한 증거예요.

작동 방식

이미지는 전체 원래 크기로 브라우저 캔버스에 그려지고, 텍스트는 선택한 정확한 크기, 색상, 투명도로 그 위에 그려져요. 텍스트 크기는 이미지 너비의 백분율이므로, 사진 너비가 800픽셀이든 8000픽셀이든 워터마크가 올바르게 조정돼요. 타일 모드에서는 텍스트가 회전하고 전체 프레임을 덮는 대각선 격자로 반복돼요, 모서리를 포함해요. 다운로드하면, 캔버스는 선택한 형식으로 내보내져요 — 텍스트는 이미지 파일의 영구적인 부분이 돼요.

적용 예시

다음인 사진에 너비 2000 px, 크기 설정은 6% 2000 × 6 ÷ 100 = 의 글꼴을 제공해요 120 px. 60% 불투명도로 오른쪽 아래 위치에 있으면, 텍스트는 양쪽 가장자리에서 작은 여백(짧은 쪽의 3%)을 두고 앉아, 휴대폰 화면에서 읽을 수 있을 만큼 크지만 주제를 가리지 않을 만큼 작아요.

자주 묻는 질문

이 워터마크 도구는 무료인가요?

네 — 완전히 무료, 회원가입 없음, 워터마크하는 이미지 수에 제한 없음. 추가되는 유일한 표시는 직접 입력한 텍스트예요.

내 사진이 서버에 업로드되나요?

아니요. 모든 것이 Canvas API를 사용해 브라우저에서 100% 일어나요. 이미지는 기기를 절대 벗어나지 않으며, 이는 도구를 즉각적으로 만들기도 해요.

단일 워터마크와 타일 패턴의 차이는 무엇인가요?

하나의 워터마크는 오른쪽 아래 모서리 같은 아홉 위치 중 하나에 앉아요 — 깔끔하고 방해되지 않아요. 타일 패턴은 텍스트를 전체 이미지에 대각선으로 반복하며, 이는 잘라내기 훨씬 어렵고 미리보기, 교정본, 스톡 스타일 공유에 가장 좋아요.

어떤 불투명도를 사용해야 하나요?

50–70%가 대부분의 사진에 적합해요: 읽을 수 있지만 방해되지 않아요. 은은한 타일 패턴에는 25–40%로 낮추고, 표시가 눈에 띄어야 할 때 — 예를 들어 문서 스캔에서는 — 90–100%를 사용하세요.

나중에 워터마크를 제거할 수 있나요?

다운로드한 파일에서는 아니에요 — 텍스트는 픽셀에 구워져 있어요. 항상 원본, 표시 없는 사진을 유지하세요. 그러면 원할 때마다 다른 텍스트나 설정으로 다시 워터마크할 수 있어요.

도구가 이미지 품질을 떨어뜨리나요?

이미지는 전체 원래 크기로 내보내져요. JPG와 WebP는 품질 슬라이더를 사용해요(기본값 92%, 사진에서 시각적으로 동일해요). 완전히 무손실인 파일은 PNG를 선택하세요.
