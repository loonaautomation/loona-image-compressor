Why convert JPG to AVIF?

AVIF typically saves 30–50% over JPG at the same quality — worth it for web delivery where browsers support it.

What changes in the file

Encoding AVIF is browser-dependent: Chrome and Edge encode it; Firefox cannot. If the tool reports that, use the WebP version of this page instead.

Worked example

A JPG file dropped above keeps its exact pixel dimensions (AVIF at the same width and height); only the encoding changes. The result line shows the before/after file size, so you can judge immediately whether the conversion helped — if the AVIF comes out larger (common for tiny JPG graphics into BMP), the honest numbers let you keep the original instead.

Frequently Asked Questions

How do I convert JPG to AVIF?

Add the JPG file above and press Convert — the browser's own image engine re-encodes it as AVIF, and you download the result. Nothing is uploaded.

Will I lose quality converting JPG to AVIF?

Encoding AVIF is browser-dependent: Chrome and Edge encode it; Firefox cannot. If the tool reports that, use the WebP version of this page instead.

Are there file size limits?

Only your device's memory. Very large images (100+ megapixels) can strain phones — desktops handle them easily.

Why might the tool refuse?

Decoding is universal for JPG/PNG/WebP/GIF/BMP/SVG in modern browsers, but ENCODING AVIF (and WebP in Firefox) is not available everywhere. The tool detects this and tells you plainly instead of producing a wrong-format file.
