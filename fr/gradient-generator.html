Générateur de dégradés CSS

Créez un dégradé linéaire depuis deux ou trois couleurs, tournez-le à n'importe quel angle avec un aperçu en direct, et copiez le CSS prêt à coller.

L'angle suit la norme CSS : 0deg pointe vers le haut, 90deg vers la droite, 180deg vers le bas. Les arrêts de couleur sont espacés régulièrement — deux couleurs à 0 % et 100 %, trois à 0 %, 50 % et 100 %.

Comment construire un dégradé CSS en 3 étapes

  1. Choisir deux ou trois couleurs — cochez la case de la troisième couleur pour un dégradé à trois arrêts.
  2. Définir l'angle — faites glisser le curseur et regardez l'aperçu tourner en temps réel.
  3. Cliquer sur le CSS pour le copier — collez-le directement dans votre feuille de style ou votre attribut style.

Des dégradés qui paraissent conçus, pas par défaut

Un dégradé linéaire mélange une couleur dans une autre le long d'une ligne droite. Les erreurs classiques sont de choisir des couleurs aux extrémités opposées de l'arc-en-ciel (le mélange devient gris boueux au milieu) et d'utiliser des arrêts d'arc-en-ciel pur. Les recettes fiables : mélangez deux nuances de la même même famille de teinte pour un arrière-plan subtil et professionnel ; ajoutez une troisième couleur quand le mélange de deux couleurs a un milieu terne ; et adaptez l'angle à la lumière de votre conception — 135° (de haut-gauche à bas-droite) convient à la plupart des écrans car il imite la lumière naturelle. Si vous avez besoin d'une paire de départ, générez d'abord une palette avec le Générateur de palettes Loona et collez ses codes HEX ici.

Comment ça marche

Le générateur écrit le CSS standard linear-gradient() fonction pour vous. Les arrêts de couleur sont espacés régulièrement : avec deux couleurs, ils se situent à 0 % et 100 % ; avec trois, à 0 %, 50 % et 100 %. L'angle utilise la convention CSS — 0deg pointe vers le haut, 90deg vers la droite, 180deg vers le bas, 270deg vers la gauche — et le navigateur lui-même rend le mélange, l'aperçu que vous voyez est donc exactement ce que produit le code copié. Aucun code ne quitte votre appareil ; le CSS est assemblé dans votre navigateur.

Exemple pratique

Choisir le rouge #ff0000 et bleu #0000ff à 90 degrés et la sortie est background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — le mélange va de gauche (0deg irait vers le haut) à droite, en commençant par le rouge pur et en finissant par le bleu pur. Ajoutez une couleur du milieu, disons le doré #d4a017, et il est placé à 50 % : linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%).

Questions fréquentes

Ce générateur de dégradés est-il gratuit ?

Oui — gratuit sans inscription, et le CSS qu'il produit est à vous pour l'utiliser partout, y compris dans des projets commerciaux.

Quelle est la différence entre 0deg et 180deg ?

Ils exécutent le même mélange dans des directions opposées : 0deg commence la première couleur en bas et mélange vers le haut ; 180deg la commence en haut et mélange vers le bas. Échangez l'angle de 180 pour inverser n'importe quel dégradé.

Puis-je faire un dégradé radial ?

Cet outil construit des dégradés linéaires, qui couvrent la plupart des besoins de conception web. Pour une version radiale, générez les couleurs ici, puis changez le nom de la fonction dans votre CSS en radial-gradient avec les mêmes arrêts de couleur.

Pourquoi mon mélange de deux couleurs paraît-il gris au milieu ?

Les couleurs opposées sur la roue s'annulent au milieu du mélange. Ajoutez une troisième couleur entre elles (cochez Couleur 3) qui fait le pont entre les deux teintes, et la bande boueuse disparaît.

Le dégradé fonctionnera-t-il dans tous les navigateurs ?

Oui — linear-gradient est pris en charge par tous les navigateurs modernes depuis plus d'une décennie, sans préfixes nécessaires. L'aperçu utilise le même CSS, ce que vous voyez est donc ce que vous obtenez.
