Генератор градиентов CSS

Создайте линейный градиент из двух или трёх цветов, поворачивайте его на любой угол с предпросмотром в реальном времени и копируйте готовый к вставке CSS.

Угол следует стандарту CSS: 0deg указывает вверх, 90deg указывает вправо, 180deg указывает вниз. Остановки цвета распределяются равномерно — два цвета на 0% и 100%, три — на 0%, 50% и 100%.

Как создать градиент CSS за 3 шага

  1. Выберите два или три цвета — отметьте третье поле цвета для градиента с тремя остановками.
  2. Установите угол — перетаскивайте ползунок и наблюдайте, как предпросмотр поворачивается в реальном времени.
  3. Нажмите CSS, чтобы скопировать его — вставьте его прямо в вашу таблицу стилей или атрибут style.

Градиенты, которые выглядят спроектированными, а не стандартными

Линейный градиент плавно переводит один цвет в другой по прямой линии. Классические ошибки — выбор цветов с противоположных концов радуги (в середине переход становится грязно-серым) и использование чистых радужных остановок. Надёжные рецепты: смешивайте два оттенка same семейство оттенков для тонкого, профессионального фона; добавьте третий цвет, когда смесь из двух цветов имеет тусклую середину; и подберите угол под свет в вашем дизайне — 135° (от левого верхнего к правому нижнему) подходит большинству экранов, потому что имитирует естественный свет. Если вам нужна начальная пара, сначала сгенерируйте палитру с помощью генератора палитры Loona и вставьте её коды HEX сюда.

Как это работает

Генератор записывает стандартную функцию CSS linear-gradient() функцию для вас. Остановки цвета распределяются равномерно: при двух цветах они находятся на 0% и 100%; при трёх — на 0%, 50% и 100%. Угол использует соглашение CSS — 0deg указывает вверх, 90deg — вправо, 180deg — вниз, 270deg — влево — а сам браузер отрисовывает смесь, поэтому предпросмотр, который вы видите, — это ровно то, что производит скопированный код. Никакой код не покидает ваше устройство; CSS собирается в вашем браузере.

Разобранный пример

Выберите красный #ff0000 и синий #0000ff под 90 градусов, и вывод — это background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — смесь идёт слева (0deg шёл бы вверх) направо, начинаясь с чистого красного и заканчиваясь чистым синим. Добавьте средний цвет, скажем золотой #d4a017, и он размещается при 50%: linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%).

Часто задаваемые вопросы

Этот генератор градиентов бесплатен?

Да — бесплатно и без регистрации, а создаваемый им CSS принадлежит вам для использования где угодно, включая коммерческие проекты.

В чём разница между 0deg и 180deg?

Они выполняют одну и ту же смесь в противоположных направлениях: 0deg начинает первый цвет внизу и смешивает вверх; 180deg начинает его вверху и смешивает вниз. Измените угол на 180, чтобы обратить любой градиент.

Могу ли я сделать радиальный градиент?

Этот инструмент создаёт линейные градиенты, которые покрывают большинство потребностей веб-дизайна. Для радиальной версии сгенерируйте цвета здесь, затем измените имя функции в вашем CSS на radial-gradient с теми же остановками цвета.

Почему моя смесь из двух цветов выглядит серой в середине?

Цвета, противоположные друг другу на круге, взаимно гасятся в середине перехода. Добавьте третий цвет между ними (отметьте Цвет 3), который соединяет два оттенка, и грязная полоса исчезнет.

Будет ли градиент работать во всех браузерах?

Да — linear-gradient поддерживается каждым современным браузером уже более десяти лет, без необходимости в префиксах. Предпросмотр использует тот же CSS, поэтому то, что вы видите, — это то, что вы получаете.
