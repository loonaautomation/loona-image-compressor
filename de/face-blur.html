So machen Sie ein Gesicht oder Detail in 3 Schritten unscharf

  1. Laden Sie Ihr Foto — ziehen Sie es oben hinein oder klicken Sie, um es auszuwählen. Es wird niemals hochgeladen; alle Bearbeitungen geschehen auf Ihrem Gerät.
  2. Zeichnen Sie Felder über das, was verborgen werden soll — ziehen Sie über jedes Gesicht, Kennzeichen, jeden Namen oder jede Dokumentennummer. Ziehen Sie ein Feld, um es zu bewegen, oder löschen Sie es aus der Liste. In manchen Chrome- und Edge-Browsern erscheint auch eine optionale Schaltfläche „Automatische Gesichtserkennung versuchen“ — die Felder bleiben so oder so immer unter Ihrer Kontrolle.
  3. Wählen Sie Unschärfe oder Verpixeln und laden Sie dann herunter — passen Sie die Stärke an, prüfen Sie die geschützte Vorschau und speichern Sie als PNG oder JPG.

Über das Unschärfen von Fotos, bevor Sie sie teilen

Screenshots und Fotos reisen weiter, als wir erwarten: Ein Klassenfoto erreicht eine Elterngruppe, eine Autoanzeige zeigt das Kennzeichen vor Ihrem Zuhause, ein Dokumentenfoto enthüllt eine Kontonummer. Die sensiblen Teile abzudecken vor dem Teilen ist die einzig sichere Reihenfolge — das Versprechen einer Plattform, später zu löschen, ist kein Ersatz. Dieses Tool ist bewusst manuell: Sie entscheiden exakt, welche Bereiche privat sind, statt einem Algorithmus zu vertrauen, dass er rät. Unschärfe sieht bei Gesichtern auf Gruppenfotos glatt und natürlich aus; Verpixeln (der Mosaikeffekt) ist die stärkere, offensichtlichere Wahl für Kennzeichen, Bildschirme und Dokumente, weil es Details zerstört, statt sie zu erweichen.

Eine ehrliche Warnung: Starke Unschärfe auf einem kleinen, scharfen Detail kann von entschlossenen Experten manchmal teilweise umgekehrt werden, und die Verpixelung von großem Text hat ebenfalls bekannte Grenzen. Für hochsensible Informationen — Ausweisnummern, Adressen, Gesichter von Kindern in riskanten Situationen — ist die sicherste Wahl eine solide Abdeckung (schneiden Sie den Bereich heraus oder decken Sie ihn in einem Editor mit einem undurchsichtigen Feld ab). Für alltägliches Teilen ist eine starke Unschärfe oder Verpixelung mit einer hohen Stärkeeinstellung der praktische Standard, den Redaktionen und Marktplätze gleichermaßen verwenden.

So funktioniert es

Das Foto wird auf eine Browser-Canvas gezeichnet. Jedes Feld, das Sie zeichnen, wird in den eigenen Pixelkoordinaten des Fotos gespeichert, sodass der Effekt in voller Auflösung exakt an derselben Stelle landet. Für Unschärfe wird das Foto durch einen Unschärfefilter neu gezeichnet, der auf jedes Feld beschnitten ist; für Verpixeln wird jeder eingefasste Bereich auf eine Handvoll großer Blöcke geschrumpft und mit deaktivierter Glättung wieder hochskaliert, was das Mosaik erzeugt. Die geschützte Vorschau unter dem Editor wird bei jeder Änderung neu erzeugt, und der Download wird in der vollen Originalgröße des Fotos exportiert.

Praxisbeispiel

Ein Gesicht, das etwa misst 120 px breit auf einem Handyfoto, mit der Standardstärke von verpixelt 18 px, wird nur 120 ÷ 18 ≈ 7 Blöcke breit — viel zu grob, als dass Merkmale erkannt werden könnten. Wenn Sie in der Vorschau noch ein Detail erkennen können, ziehen Sie die Stärke hoch: Bei 30 px ist dasselbe Gesicht nur 4 Blöcke breit.

Häufig gestellte Fragen

Ist dieses Gesichtsunschärfe-Tool kostenlos?

Ja — völlig kostenlos, ohne Anmeldung und ohne Begrenzung, wie viele Fotos Sie schützen.

Wird mein Foto irgendwo hochgeladen oder gescannt?

Nein. Ihr Foto verlässt Ihr Gerät nie, und das manuelle Zeichnen der Felder braucht überhaupt keinen Server. Die optionale Auto-Erkennen-Schaltfläche, wo ein Browser sie anbietet, läuft ebenfalls vollständig auf Ihrem Gerät mit dem eingebauten FaceDetector des Browsers.

Warum muss ich die Felder selbst zeichnen?

Weil nur Sie wissen, was privat bleiben muss — ein Gesicht, ein Kennzeichen, eine Hausnummer, ein Name auf einem Zertifikat. Manuelle Auswahl funktioniert in jedem Browser, für jede Art von Detail, und sie übersieht niemals ein Gesicht, wie die automatische Erkennung es manchmal tut. Wenn Ihr Browser Gesichtserkennung unterstützt, können Sie die Auto-Erkennen-Schaltfläche als Ausgangspunkt verwenden und die Felder dann von Hand korrigieren.

Was ist sicherer, Unschärfe oder Verpixeln?

Verpixeln mit hoher Stärke zerstört mehr Informationen und ist die bessere Wahl für Text, Zahlen und Kennzeichen. Unschärfe sieht bei Gesichtern auf gewöhnlichen Fotos natürlicher aus. Für wirklich sensible Inhalte ist das vollständige Herausschneiden des Bereichs am sichersten von allem.

Kann jemand mein Foto danach wieder scharf machen?

Der Download ist ein neues, abgeflachtes Bild — die originalen scharfen Pixel innerhalb der Felder werden darin nicht gespeichert, sodass beiläufige Entscharfungs-Tools nichts wiederherzustellen haben. Extrem entschlossene Analyse kann stark unscharfe Inhalte manchmal schätzen, weshalb die Anleitung oben empfiehlt, die sensibelsten Details stattdessen abzudecken oder herauszuschneiden.

Verkleinert das Tool mein Foto?

Nein. Das geschützte Bild wird in den vollen ursprünglichen Abmessungen des Fotos exportiert, in PNG (verlustfrei) oder JPG mit dem Qualitätsregler.
