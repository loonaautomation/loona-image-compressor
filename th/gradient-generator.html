เครื่องสร้างการไล่ระดับ CSS

สร้าง การไล่ระดับเชิงเส้น จากสองหรือสามสี หมุนมันเป็นมุมใดก็ได้ด้วยตัวอย่างแบบเรียลไทม์ และคัดลอก CSS ที่พร้อมวาง

มุมเป็นไปตามมาตรฐาน CSS: 0deg ชี้ขึ้น 90deg ชี้ขวา 180deg ชี้ลง จุดหยุดสีมีระยะห่างสม่ำเสมอ — สองสีที่ 0% และ 100% สามสีที่ 0%, 50% และ 100%

วิธีสร้างการไล่ระดับ CSS ใน 3 ขั้นตอน

  1. เลือกสองหรือสามสี — ติ๊กกล่องสีที่สามสำหรับการไล่ระดับสามจุดหยุด
  2. ตั้งมุม — ลากแถบเลื่อนและดูตัวอย่างหมุนแบบเรียลไทม์
  3. คลิก CSS เพื่อคัดลอกมัน — วางมันตรงลงในสไตล์ชีตหรือแอตทริบิวต์สไตล์ของคุณ

การไล่ระดับที่ดูออกแบบ ไม่ใช่ค่าเริ่มต้น

การไล่ระดับเชิงเส้นผสมสีหนึ่งเข้าไปอีกสีหนึ่งตามเส้นตรง ความผิดพลาดคลาสสิกคือการเลือกสีจากปลายตรงข้ามของรุ้ง (การผสมเปลี่ยนเป็นสีเทาขุ่นตรงกลาง) และการใช้จุดหยุดรุ้งบริสุทธิ์ สูตรที่เชื่อถือได้: ผสมสองเฉดของ same ตระกูลเฉดสำหรับพื้นหลังที่ละเอียดอ่อนและเป็นมืออาชีพ เพิ่มสีที่สามเมื่อการผสมสองสีมีกลางที่หมอง และจับคู่มุมกับแสงในการออกแบบของคุณ — 135° (จากบนซ้ายไปล่างขวา) เหมาะกับหน้าจอส่วนใหญ่เพราะมันเลียนแบบแสงธรรมชาติ หากคุณต้องการคู่เริ่มต้น ให้สร้างพาเลตก่อนด้วยเครื่องสร้างพาเลตของ Loona และวางโค้ด HEX ของมันที่นี่

มันทำงานอย่างไร

เครื่องสร้างเขียน CSS มาตรฐาน linear-gradient() ฟังก์ชันสำหรับคุณ จุดหยุดสีมีระยะห่างสม่ำเสมอ: ด้วยสองสีพวกมันอยู่ที่ 0% และ 100% ด้วยสามสี ที่ 0%, 50% และ 100% มุมใช้แบบแผน CSS — 0deg ชี้ขึ้น 90deg ไปทางขวา 180deg ลง 270deg ไปทางซ้าย — และเบราว์เซอร์เองเรนเดอร์การผสม ตัวอย่างที่คุณเห็นจึงเป็นสิ่งที่โค้ดที่คัดลอกสร้างพอดี ไม่มีโค้ดออกจากอุปกรณ์ของคุณ CSS ถูกประกอบในเบราว์เซอร์ของคุณ

ตัวอย่างที่ทำแล้ว

เลือกสีแดง #ff0000 และสีน้ำเงิน #0000ff ที่ 90 องศาและผลลัพธ์คือ background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — การผสมทำงานจากซ้าย (0deg จะวิ่งขึ้น) ไปขวา เริ่มจากแดงบริสุทธิ์และสิ้นสุดที่น้ำเงินบริสุทธิ์ เพิ่มสีกลาง เช่นทอง #d4a017, และมันถูกวางที่ 50%: linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%).

คำถามที่พบบ่อย

เครื่องสร้างการไล่ระดับนี้ฟรีไหม?

ใช่ — ฟรี ไม่ต้องสมัครสมาชิก และ CSS ที่มันสร้างเป็นของคุณเพื่อใช้ที่ใดก็ได้ รวมถึงโครงการเชิงพาณิชย์

ความแตกต่างระหว่าง 0deg และ 180deg คืออะไร?

พวกมันรันการผสมเดียวกันในทิศทางตรงกันข้าม: 0deg เริ่มสีแรกที่ด้านล่างและผสมขึ้น 180deg เริ่มที่ด้านบนและผสมลง สลับมุม 180 เพื่อย้อนการไล่ระดับใด ๆ

ฉันสามารถทำการไล่ระดับรัศมีได้ไหม?

เครื่องมือนี้สร้างการไล่ระดับเชิงเส้น ซึ่งครอบคลุมความต้องการออกแบบเว็บส่วนใหญ่ สำหรับเวอร์ชันรัศมี ให้สร้างสีที่นี่ จากนั้นเปลี่ยนชื่อฟังก์ชันใน CSS ของคุณเป็น radial-gradient ด้วยจุดหยุดสีเดียวกัน

ทำไมการผสมสองสีของฉันดูเป็นสีเทาตรงกลาง?

สีที่อยู่ตรงข้ามกันบนวงล้อจะยกเลิกกันกลางการผสม เพิ่มสีที่สามระหว่างพวกมัน (ติ๊กสี 3) ที่เชื่อมสองเฉด และแถบขุ่นจะหายไป

การไล่ระดับจะทำงานในทุกเบราว์เซอร์ไหม?

ใช่ — linear-gradient ได้รับการรองรับจากทุกเบราว์เซอร์สมัยใหม่มากว่าทศวรรษ โดยไม่ต้องใช้คำนำหน้า ตัวอย่างใช้ CSS เดียวกัน ดังนั้นสิ่งที่คุณเห็นคือสิ่งที่คุณได้
