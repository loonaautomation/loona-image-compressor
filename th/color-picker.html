ตัวเลือกสี

เลือกสีและดู HEX, RGB, HSL และ HSV ค่าด้วยกัน — คลิกค่าใดก็ได้เพื่อคัดลอกมัน และสำรวจสีอ่อนและสีเข้มที่เข้ากัน ทุกอย่างทำงานในเบราว์เซอร์ของคุณ

HEX#d4a017แตะเพื่อคัดลอก
RGBrgb(212, 160, 23)แตะเพื่อคัดลอก
HSLhsl(43, 80%, 46%)แตะเพื่อคัดลอก
HSVhsv(43, 89%, 83%)แตะเพื่อคัดลอก

สีอ่อน & สีเข้ม

สีเดียวกันผสมไปทางขาว (สีอ่อน ซ้าย) และไปทางดำ (สีเข้ม ขวา) คลิกขั้นตอนใดก็ได้เพื่อโหลดมัน

วิธีเลือกสีและคัดลอกโค้ดของมันใน 3 ขั้นตอน

  1. เลือกสี — ใช้บ่อสี พิมพ์ค่า HEX หรือลากแถบเลื่อน RGB และ HSL
  2. อ่านทุกรูปแบบ — HEX, RGB, HSL และ HSV อัปเดตด้วยกัน ทันที
  3. คลิกเพื่อคัดลอก — คลิกแถวค่าใดก็ได้ (หรือขั้นสีอ่อน/สีเข้มใดก็ได้) เพื่อคัดลอกมันและใช้มันในการออกแบบ CSS หรือการแก้ไขรูปถ่ายของคุณ

หนึ่งสี สี่ภาษา

นักออกแบบ นักพัฒนา และผู้แก้ไขรูปถ่ายทั้งหมดอธิบายสีเดียวกันแตกต่างกัน HEX (#d4a017) เป็นชวเลขที่ใช้ในการออกแบบเว็บและ CSS RGB แสดงปริมาณแสงแดง เขียว และน้ำเงินที่จะผสม — ภาษาของหน้าจอ HSL และ HSV อธิบายสีในแบบที่ผู้คนคิดถึงมัน: เฉดบนวงล้อสี มันสดแค่ไหน และมันสว่างหรือสว่างแค่ไหน การแปลงระหว่างพวกมันด้วยมือมักผิดพลาด เครื่องมือนี้รักษาทั้งสี่ให้ตรงกันขณะที่คุณทดลอง และแถบสีอ่อนและสีเข้มแสดงเฉดเดียวกันผสมไปทางขาวและไปทางดำในขั้น 20% ที่สม่ำเสมอ — วิธีที่เร็วที่สุดในการสร้างสถานะโฮเวอร์ สีขอบ หรือพื้นหลังนุ่มที่ยังคงเป็นของครอบครัวเดียวกัน

มันทำงานอย่างไร

HEX คือ RGB ที่เขียนในฐาน 16: ตัวเลขแต่ละคู่คือหนึ่งช่องจาก 0 (00) ถึง 255 (ff) HSL คำนวณจากช่อง RGB ที่ใหญ่ที่สุดและเล็กที่สุด: ความสว่างคือจุดกึ่งกลางของพวกมัน ความอิ่มสีคือช่องว่างระหว่างพวกมันที่ปรับขนาดโดยจุดกึ่งกลางนั้น และเฉดคือมุมบนวงล้อสีที่ชี้ไปยังช่องเด่น HSV (เรียกอีกอย่างว่า HSB) ใช้เฉดเดียวกัน แต่วัดความอิ่มเทียบกับช่องที่สว่างที่สุดและรายงานช่องนั้นโดยตรงเป็นค่า การแปลงทั้งหมดทำงานในเบราว์เซอร์ของคุณด้วยคณิตศาสตร์สี CSS มาตรฐาน — ไม่มีรูปภาพหรือสีใดออกจากอุปกรณ์ของคุณ

ตัวอย่างที่ทำแล้ว

นำสีส้ม #FF6600. ใน RGB นั่นคือ rgb(255, 102, 0) — แดงเต็ม เขียวบ้าง ไม่มีน้ำเงิน การแปลง HSL ให้ hsl(24°, 100%, 50%): เฉด 24° นั่งระหว่างแดง (0°) และเหลือง (60°) พอดีที่ส้มอยู่ ที่ความอิ่มเต็มและความสว่างครึ่ง HSV รายงาน hsv(24°, 100%, 100%) — เฉดเดียวกัน ความอิ่มเต็ม ความสว่างเต็ม เพราะช่องที่แข็งแกร่งที่สุด (แดง) อยู่ที่สูงสุดของมัน

คำถามที่พบบ่อย

ตัวเลือกสีนี้ฟรีไหม?

ใช่ — ฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก และไม่มีขีดจำกัด คลิกค่าใดก็ได้เพื่อคัดลอกมัน

ความแตกต่างระหว่าง HSL และ HSV คืออะไร?

พวกมันใช้เฉดเดียวกัน ความสว่าง HSL เป็นจุดกึ่งกลางระหว่างช่องที่สว่างที่สุดและมืดที่สุด 50% ของความสว่างจึงเป็นสีบริสุทธิ์ ค่า HSV คือช่องที่สว่างที่สุด ดังนั้นค่า 100% คือสีบริสุทธิ์ที่ความสว่างเต็ม เครื่องมือออกแบบแตกต่างกัน: Figma แสดง HEX/RGB/HSL ตัวเลือกของ Photoshop เป็นแบบ HSV

ฉันสามารถพิมพ์โค้ด HEX ที่ฉันมีอยู่แล้วได้ไหม?

ใช่ — พิมพ์หรือวางค่า HEX 3 หรือ 6 หลักใดก็ได้ (มีหรือไม่มี #) ลงในกล่อง HEX และกด Enter รูปแบบอื่นทั้งหมดและชุดแถบเลื่อนทั้งสองจะอัปเดตพร้อมกัน

สีอ่อนและสีเข้มคืออะไร?

สีอ่อนคือสีผสมกับขาว สีเข้มคือสีผสมกับดำ แถบใต้ตัวเลือกย้ายในขั้น 20% ซึ่งเป็นสูตรที่ใช้งานได้จริงสำหรับการจับคู่สีโฮเวอร์ ขอบ และพื้นหลัง

สิ่งนี้ทำงานสำหรับสีการพิมพ์ (CMYK) ไหม?

เครื่องมือนี้ครอบคลุมโมเดลสีหน้าจอ (HEX, RGB, HSL, HSV) การแปลง CMYK ขึ้นกับโปรไฟล์เครื่องพิมพ์ ดังนั้นสำหรับงานพิมพ์ ให้ใช้ค่าเหล่านี้เป็นจุดเริ่มต้นและทดลองพิมพ์บนกระดาษ
