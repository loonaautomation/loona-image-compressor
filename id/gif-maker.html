Cara membuat GIF dalam 4 langkah

  1. Tambahkan gambar Anda — jatuhkan di atas atau klik untuk menelusuri. Tidak ada yang diunggah; file tetap di perangkat Anda.
  2. Susun bingkainya — seret bingkai untuk mengurutkan, atau gunakan tombol naik dan turun. Hapus bingkai yang tidak Anda perlukan.
  3. Atur waktu dan ukuran — pilih jeda bingkai (lebih kecil berarti lebih cepat), lebar hasil, dan secara opsional jeda berbeda untuk satu bingkai. Lihat pratinjau langsung saat Anda menyesuaikan.
  4. Buat dan unduh — tekan Buat GIF, lihat kemajuannya, lalu unduh GIF animasi berulang Anda.

Mengapa membuat GIF Anda di sini?

Kebanyakan pembuat GIF online mengunggah foto Anda ke server terlebih dahulu. Loona GIF Maker tidak pernah melakukannya: encoder gif.js gratis dan sumber terbuka berjalan sepenuhnya di browser Anda, jadi gambar Anda tidak pernah meninggalkan perangkat Anda, tanpa pendaftaran, tanpa tanda air, dan tanpa batas dari kami. GIF yang selesai berputar selamanya dan berfungsi di mana pun GIF dibagikan.

Pertanyaan yang sering diajukan

Apakah Loona GIF Maker gratis?

Ya. Loona GIF Maker sepenuhnya gratis — tanpa pendaftaran, tanpa tanda air, tanpa masa percobaan, dan tanpa batas jumlah GIF yang Anda buat.

Apakah gambar saya diunggah ke server?

Tidak. Semuanya berjalan 100% di browser Anda dengan JavaScript. Gambar Anda tidak pernah meninggalkan perangkat Anda — tidak seperti pembuat GIF berbasis server seperti Ezgif, yang mengharuskan Anda mengunggah file terlebih dahulu.

Apakah ada batas jumlah gambar atau ukuran file?

Kami tidak memberlakukan batas buatan. Anda dapat menambahkan gambar sebanyak yang Anda suka; kumpulan foto besar dalam jumlah sangat banyak mungkin lambat di ponsel kelas bawah, jadi mengurangi lebar hasil akan membantu.

Format gambar apa saja yang dapat saya gunakan?

Format apa pun yang dapat ditampilkan browser Anda — JPG, PNG, WebP, GIF, BMP, dan lainnya. Bingkai-bingkai tersebut digabungkan menjadi satu GIF animasi.

Akankah GIF saya berputar selamanya?

Ya. GIF yang dibuat di sini diatur untuk berputar selamanya (repeat 0), jadi GIF akan terus diputar di mana pun diposting.

Bisakah saya mengubah kecepatan bingkai individual?

Ya. Atur jeda bingkai global untuk seluruh GIF, lalu timpa jeda pada bingkai mana pun dalam daftar bingkai.
