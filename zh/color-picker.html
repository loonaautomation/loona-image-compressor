一种颜色，四种语言

设计师、开发人员和照片编辑人员对同一种颜色的描述各不相同。HEX（#d4a017）是网页设计和 CSS 中使用的简写。RGB 列出了要混合多少红光、绿光和蓝光 — 这是屏幕的语言。HSL 和 HSV 以人们思考颜色的方式来描述颜色：色轮上的色调、它的鲜艳程度，以及它的明亮程度。手动在它们之间转换容易出错；本工具在您尝试时会保持四者同步，色调和阴影条以均匀的 20% 步长显示同一色调向白色和向黑色混合的结果 — 这是构建悬停状态、边框颜色或仍属于同一家族的柔和背景的最快方法。

它如何工作

HEX 只是以 16 进制书写的 RGB：每对数字是一个从 0（00）到 255（ff）的通道。HSL 从最大和最小的 RGB 通道计算得出：亮度是它们的中点，饱和度是它们之间的差距按该中点缩放，色调是色轮上指向主导通道的角度。HSV（也称为 HSB）使用相同的色调，但相对于最亮的通道测量饱和度，并将该通道直接报告为值。所有转换都使用标准 CSS 颜色数学在您的浏览器中运行 — 没有图片或颜色会离开您的设备。

实例讲解

取橙色 #FF6600。在 RGB 中，那是 rgb(255, 102, 0) — 全红、一些绿、无蓝。HSL 转换得到 hsl(24°, 100%, 50%)：24° 的色调位于红色（0°）和黄色（60°）之间，正是橙色所在的位置，饱和度为满，亮度为一半。HSV 报告 hsv(24°, 100%, 100%) — 相同的色调、完全饱和、完全亮度，因为最强的通道（红色）处于最大值。

常见问题

这个颜色选择器免费吗？

是的 — 完全免费、无需注册、无限制。点击任何值以复制它。

HSL 和 HSV 之间有什么区别？

它们共享相同的色调。HSL 亮度是最亮和最暗通道之间的中点，因此 50% 亮度是纯色。HSV 值就是最亮的通道，因此 100% 值是全亮度下的纯色。设计工具各不相同：Figma 显示 HEX/RGB/HSL，Photoshop 的选择器基于 HSV。

我可以输入我已有的 HEX 代码吗？

是的 — 在 HEX 框中输入或粘贴任何 3 位或 6 位 HEX 值（带或不带 #），然后按 Enter。所有其他格式和两组滑块同时更新。

什么是色调和阴影？

色调是与白色混合的颜色；阴影是与黑色混合的颜色。选择器下方的条以 20% 的步长移动，这是匹配悬停、边框和背景颜色的实用方法。

这适用于印刷颜色（CMYK）吗？

本工具涵盖屏幕颜色模型（HEX、RGB、HSL、HSV）。CMYK 转换取决于打印机配置文件，因此对于打印工作，请将这些值用作起点并在纸上校样。
