CSS 渐变生成器

构建一个 线性渐变 从两种或三种颜色生成，将其转动到任何角度（带实时预览），并复制可直接粘贴的 CSS。

角度遵循 CSS 标准：0deg 指向上，90deg 指向右，180deg 指向下。色标均匀分布 — 两种颜色在 0% 和 100%，三种在 0%、50% 和 100%。

如何通过 3 个步骤构建 CSS 渐变

  1. 选择两种或三种颜色 — 勾选第三个颜色框以获得三段渐变。
  2. 设置角度 — 拖动滑块，观看预览实时旋转。
  3. 点击 CSS 以复制它 — 将其直接粘贴到您的样式表或样式属性中。

看起来是设计出来的渐变，而不是默认的

线性渐变沿直线将一种颜色混合到另一种颜色中。经典的错误是从彩虹的两端选择颜色（混合在中间变成浑浊的灰色）和使用纯彩虹色标。可靠的方法是：混合以下颜色的两种色调： 相同 色调系列，用于微妙、专业的背景；当双色混合的中间暗淡时，添加第三种颜色；并使角度与您设计中的光线相配 — 135°（左上到右下）适合大多数屏幕，因为它模仿自然光。如果您需要一个起始配对，先用 Loona 调色板生成器生成一个调色板，并将其 HEX 代码粘贴到此处。

它如何工作

生成器写入标准 CSS linear-gradient() 为您（生成渐变的）函数。色标均匀分布：两种颜色时它们位于 0% 和 100%；三种时位于 0%、50% 和 100%。角度使用 CSS 约定 — 0deg 指向上，90deg 指向右，180deg 指向下，270deg 指向左 — 浏览器本身渲染混合，因此您看到的预览正是复制的代码产生的结果。没有代码离开您的设备；CSS 在您的浏览器中组装。

实例讲解

选择红色 #ff0000 和蓝色 #0000ff 在 90 度时，输出是 background: linear-gradient(90deg, #ff0000 0%, #0000ff 100%); — 混合从左（0deg 会向上运行）到右运行，从纯红开始，到纯蓝结束。添加中间颜色，比如金色 #d4a017，并将其放置在 50%： linear-gradient(90deg, #ff0000 0%, #d4a017 50%, #0000ff 100%)。

常见问题

这个渐变生成器免费吗？

是的 — 免费、无需注册，它产生的 CSS 是您的，可以在任何地方使用，包括商业项目。

0deg 和 180deg 之间有什么区别？

它们以相反方向运行相同的混合：0deg 从底部开始第一种颜色并向上混合；180deg 从顶部开始并向下混合。将角度交换 180 以反转任何渐变。

我可以制作径向渐变吗？

本工具构建线性渐变，它覆盖了大多数网页设计需求。对于径向版本，在此处生成颜色，然后将 CSS 中的函数名更改为 radial-gradient，使用相同的色标。

为什么我的双色混合在中间看起来是灰色的？

色轮上彼此相对的颜色在混合中途会相互抵消。在它们之间添加第三种颜色（勾选颜色 3）来连接两种色调，浑浊的带就会消失。

渐变会在所有浏览器中都有效吗？

是的 — linear-gradient 已经被每个现代浏览器支持了十多年，无需前缀。预览使用相同的 CSS，因此您所见即所得。
