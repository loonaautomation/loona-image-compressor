关于去除签名背景，实话实说

表格、合同、申请和信件常常需要把签名落在文件上面，但拍下来的签名照片四周总带着一圈纸。这个工具就是用来去掉这张纸的：它先根据照片四角估算纸张的颜色，再把每个像素与纸色的距离转换成透明度。深色的墨迹保持完全不透明，纸张变成完全透明，中间柔和的边缘像素则变成半透明，这样签名放到任何文件上都自然贴合。

请带着实事求是的预期来使用它：这不是人工智能，也不会描摹你的签名。它在光线均匀的素色纸面上效果最好。如果纸面上有很深的阴影、铅笔笔迹非常淡，或者墨水颜色和纸色几乎一样，就需要拖动滑块调整，有时还得重新拍一张更好的照片。在日光下拍摄的白纸签名，通常几秒钟就能处理干净。请只使用你自己的签名，或你有权使用的签名。

工作原理

你的照片会按原始尺寸绘制到画布上。工具先对四角的像素取平均，估算出纸张颜色，然后测量每个像素与该颜色的距离。「背景去除」滑块决定分界线：接近纸色的像素变成透明，远离纸色的像素保留为墨迹，中间则平滑过渡，因此笔锋边缘不会显得被啃过一样。「清理」会先把每个像素与照片的模糊副本作比较，抹平阴影或纸张弯曲造成的缓慢明暗变化，然后再去除细小的孤立斑点。如果开启纯黑，墨迹颜色会被替换为实心黑色，而透明形状保持不变。

实际示例

这是一个在白纸上用蓝笔签名的拍摄示例：四个角的平均值约为 RGB 238, 236, 228（纸张颜色），而笔迹则在 RGB 40, 60, 140 附近。在默认设置下，纸张及其柔和的阴影（约 RGB 205, 200, 188）都落在去除范围内，变成透明；而笔迹离纸色很远，因此保持完全不透明，并保留原来的蓝色。开启纯黑后，同样的形状会变成实心的黑色签名，可以直接用于打印表格。

不会。所有处理都通过 Canvas API 在你的浏览器中百分之百完成。你的签名图片永远不会离开你的设备，这一点很重要，因为签名属于敏感信息。

为什么墨迹周围还留着一些纸？

那一块的纸比其他地方更暗，通常是阴影或折痕造成的。把「背景去除」滑块稍微调高，或者先调高「清理」来抹平明暗，再试一次。

为什么我签名中较淡的部分消失了？

那一笔太淡了，在工具看来很像纸。把「背景去除」滑块往低调，直到笔迹重新出现，然后只加上你需要的清理强度。

可以用于印章吗？

可以，请点「印章模式」预设。它会使用更强的去除力度和纯黑墨色，适合大多数盖在纸上的印章。
