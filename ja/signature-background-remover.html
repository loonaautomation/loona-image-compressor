無料 署名背景リムーバー

紙の上に書かれた署名やスタンプの写真やスキャンを、きれいな透明PNGに変換します。紙は消え、インクだけが残ります。AIもアップロードも不要で、正直なキャンバス計算がブラウザの中で100％実行されます。

🖊️
署名の写真をここにドロップするか、クリックして選択してください
JPG、PNG、WebPに対応しています。無地の紙に書いた署名やスタンプを、均一な明るさで撮影したものが最適です。

値を上げると、薄い影も含めて紙がより多く除去されます。値を下げると、とても薄いインクの線も残ります。

紙のムラのある陰影を均一にし、小さなゴミや汚れを取り除きます。

プリセットを使うとスライダーが自動で設定されます。「署名」は紙に書いたペン用、「スタンプ」はインクスタンプ用です。

オンにすると、出力されるインクは真っ黒になります。オフにすると、元のインクの色がそのまま残ります（青いペンは青いままです）。

サンプル文書
署名：

まず署名の写真を読み込んでください。

写真に真っ白な背景や青い背景を付けたい場合は、代わりに写真の背景チェンジャーをご利用ください。

署名の背景を3ステップで削除する方法

  1. 写真を読み込む — 上のエリアに署名やスタンプの写真またはスキャンをドロップしてください。何もアップロードされず、画像はお使いのデバイスの中に留まります。
  2. 紙を取り除く — ツールが紙の色を測定し、紙のように見える部分をすべて透明へとフェードさせ、より濃いインクを残します。影が残る場合は「背景の削除」スライダーを、ゴミや陰影には「クリーンアップ」をお使いください。
  3. 確認してダウンロード — 市松模様の上、白い背景の上、サンプル文書の上で結果をプレビューし、透明なPNGをダウンロードして、あらゆる書類や手紙、PDFの上に配置してください。

署名の背景を削除することについて、正直にお伝えします

申込書や契約書、手紙などでは、書類の上に署名が必要です。しかし署名を撮影すると、周りに紙の部分まで写ってしまいます。このツールはその紙の部分を取り除きます。写真の四隅から紙の色を推定し、各ピクセルが紙の色からどれだけ離れているかを透明度に変換します。濃いインクはそのまま不透明に残り、紙は完全に透明になり、その間の柔らかな縁の部分は半透明になるため、どんな書類の上にも自然になじみます。

ご利用にあたっては、過度な期待はしないでください。このツールはAIではありませんし、署名をなぞって切り取るものでもありません。均一な明るさで撮影した無地の紙で最もうまく機能します。紙全体にかかる濃い影や、とても薄い鉛筆の線、紙とほぼ同じ色のインクの場合はスライダーの調整が必要で、場合によっては撮り直した方がよいこともあります。日中の光で白い紙に書いた署名を撮影すれば、通常は数秒できれいに仕上がります。ご自身の署名、または使用する許可を得た署名のみをご利用ください。

仕組み

写真は元のサイズのままキャンバスに描画されます。ツールは四隅のピクセルを平均して紙の色を推定し、次に各ピクセルがその色からどれだけ離れているかを測ります。「背景の削除」スライダーがその境界を決めます。紙の色に近いピクセルは透明に、遠いピクセルはインクとして残り、その間は滑らかに変化するため、ペンの縁がギザギザになりません。「クリーンアップ」は、まず各ピクセルをぼかしたコピーと比較することで、影や紙の反りによる緩やかな明るさの変化を均一にし、次に小さな孤立したゴミを取り除きます。純粋な黒をオンにすると、透明な形はそのままに、インクの色だけが真っ黒に置き換わります。

実例

白い紙に青いペンで書いた署名を撮影した例です。四隅の平均はおよそ RGB 238, 236, 228（紙の色）となり、ペンの線は RGB 40, 60, 140 付近にあります。初期設定では、紙とその柔らかな影（およそ RGB 205, 200, 188）は削除範囲に入って透明になりますが、紙の色から大きく離れたペンの線は不透明なまま残り、青色も保持されます。純粋な黒に切り替えると、同じ形が真っ黒な署名になり、印刷用の書類にそのまま使えます。

よくある質問

この署名背景リムーバーは無料ですか？

はい。完全に無料で、登録不要、透かしなし、処理できる署名の数にも制限はありません。

私の署名はどこかにアップロードされますか？

いいえ。すべての処理は Canvas API を使って、お使いのブラウザの中で100％完結します。署名の画像がデバイスの外に出ることは決してありません。署名は機密性の高い情報ですから、これは大切な点です。

インクの周りに紙がまだ残ってしまうのはなぜですか？

その部分の紙が他より暗くなっているためで、通常は影や折り目のせいです。「背景の削除」スライダーを少し上げるか、「クリーンアップ」を上げて先に陰影を均一にしてみてください。

署名の薄い部分が消えてしまったのはなぜですか？

その線がとても薄いため、ツールには紙のように見えているからです。「背景の削除」スライダーを、線が戻ってくるまで下げてから、「クリーンアップ」は必要な分だけ少しずつ加えてください。

ゴム印（スタンプ）にも使えますか？

はい。「スタンプモード」プリセットを押してください。より強力な削除と真っ黒なインクが適用され、紙に押したほとんどのスタンプに適しています。

結果はどのような形式になりますか？

本当に透明な背景を持つ PNG で、元の写真と同じサイズで出力されます。Word や PDF 編集ソフト、オフィスアプリで、あらゆる文書や書類、画像の上に重ねて配置できます。
